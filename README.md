# Learning Resources

A collection of theory-first learning guides covering machine learning, deep learning, C++, and high-frequency trading systems.

The notes focus on intuition, core concepts, tradeoffs, and how ideas connect. They are organized for both sequential study and quick revision.

## Guides

| Guide | Coverage |
| --- | --- |
| [Machine Learning](ml-guide/README.md) | Data preparation, feature engineering, classical ML models, evaluation, ensembles, clustering, and hyperparameter tuning |
| [Deep Learning](dl-guide/README.md) | Neural-network foundations, backpropagation, training techniques, CNNs, RNNs, LSTMs, attention, and Transformers |
| [HFT and C++](HFT-guide/00-index.md) | Modern C++ for low-latency systems, computer architecture and operating systems, market microstructure, and HFT infrastructure |

## Suggested learning path

1. Begin with the [Machine Learning guide](ml-guide/README.md) for foundational concepts.
2. Continue with the [Deep Learning guide](dl-guide/README.md) for neural networks and modern architectures.
3. Use the [HFT guide](HFT-guide/00-index.md) for C++, systems knowledge, and quantitative-trading infrastructure.

Each guide contains its own table of contents and recommended reading order.
